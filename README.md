# 김건희 자기소개 페이지

GTA 시리즈와 영화, 음악을 좋아하고 일렉·통기타 연주를 즐기는 경영정보학과 김건희를 소개하는 웹페이지입니다.

## 만든 사람

김건희 · 경영정보학과

## 프로젝트 소개

이 프로젝트는 HTML 한 파일로 만든 반응형 자기소개 페이지입니다. CSS와 JavaScript를 `index.html`에 함께 작성했으며, 다크 테마를 기본으로 하고 라이트 테마 전환 기능도 제공합니다. 본문은 Pretendard, 제목과 강조 문구는 Sandoll Nemony2 글꼴을 우선 사용합니다.

## 실행 방법

`index.html` 파일을 웹 브라우저에서 열면 확인할 수 있습니다.
